## 1. 本批新增修复：缺少签名身份时提前退出

[正式构建脚本](<scripts/build.sh#L80-L89>) 使用 `set -euo pipefail`，旧的 `SIG_ID="$(security … | grep SevenZZDev | awk … | head -1)"` 在无匹配身份时使赋值整体退出 1，脚本在既有 ad-hoc 分支之前终止。这是原有构建缺陷，不是本轮媒体生产源码修改引入。

只在该管道末尾增加 `|| true`，让无匹配保持空字符串并进入原有 `else`。没有更改身份名称、签名参数、entitlements、版本算法或构建入口；有 SevenZZDev 时的原始参数完整保留。

新增 [真实脚本片段测试](<tests/Tests/BuildSigningFallbackTests.py>) 和 [独立入口](<tests/Tests/build-signing-fallback.sh>)：抽取实际生产身份选择及分支，用系统 `/bin/bash`、`set -euo pipefail` 执行，仅替换 security/codesign 边界函数，不复制等价判断、不访问真实钥匙串。

```bash
bash tests/Tests/build-signing-fallback.sh
```

- 修复前：**exit 1**，4 场景中 3 失败；无身份、只有其它身份、查询失败均在签名前退出；匹配身份成功。见 [旧红](<build/final-build-fallback-fix-20261110/selection-red.log>)。
- 修复后：**exit 0**，`BUILD-SIGNING-FALLBACK checks=4 failed=0`。四场景完整签名 argv 均符合预期。见 [新绿](<build/final-build-fallback-fix-20261110/selection-green.log>)。
- `bash tests/Tests/run-suites.sh --strict build-signing-fallback`：**exit 0**，1 PASS / 0 FAIL / 0 incomplete。见 [严格入口](<build/final-build-fallback-fix-20261110/selection-strict.log>)。
