## 生产改动

- [翻译器接口](<src/Features/ResourceDetector/ResourceTitleTranslator.h>) 保持原 `init` / `initWithSessionConfiguration:` 兼容，新增可注入 `allowsNetworkTranslation:`；默认均为 NO。
- [翻译器实现](<src/Features/ResourceDetector/ResourceTitleTranslator.m>)：默认仅用已有离线字典；未命中返回空串，协调器保留原题；中文短路不请求。显式许可后保留原第三方 GET / 语言对 / 二跳及分段回退能力，未以 GET 改 POST 掩盖外发。
- 生产配置接在 [协调器初始化](<src/App/RDMetadataRecoveryCoordinator.m>)：只有进程环境变量 **`RD_TITLE_TRANSLATION_NETWORK=1`** 精确匹配时允许第三方网络翻译；缺失、0、true、yes、01、前置空格均不启用。技术配置在创建协调器时读取，不新增设置页或弹窗、不读写用户偏好。显式启用意味着标题会发送给 MyMemory 第三方；默认关闭会降低离线词表之外的自动翻译覆盖率，未命中保留原文。
- 所有异步操作由主线程管理：normalized source + 实例固定许可构成去重边界，同标题并发共享 inflight operation，不建立持久缓存。每个 operation 使用 generation 和对象身份守卫。
- `cancelAll` 先失效 generation、移除 operation 所有权、分离并置空旧 session，再取消旧 session；每位待完成订阅者异步主线程收到一次空结果。取消后允许重新请求；旧完成不能继续发分段、删除新 operation 或重复完成。完成前移走订阅数组，回调重入不干扰新请求。后台调用入口先转主线程，才执行 HTML 标题规范化。
