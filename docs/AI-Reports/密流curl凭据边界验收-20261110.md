# curl 凭据边界与匿名逐跳净化验收

日期：2026-11-10。执行者独占串行施工；仅完成本批 curl 边界，不实施 native 认证 provider，不改 UI，不构建或安装 App。

## 1. 结论

- **带认证头或 native-only 认证上下文的下载请求仅走原生。** 接受时复制请求并快照要求；原生失败直接交还同一 URL / response / error 对象，不剥头后匿名重试、不从原始请求恢复凭据。
- 敏感头按**存在**判定，不区分大小写，`Cookie`、`Authorization`、`Proxy-Authorization` 的空值亦禁止 curl。首发和 fresh reissue 共用守卫；原生成功仍正常交还。
- 共享 native-only 标记是 `NSURLProtocol` 请求属性，不是 HTTP 字段；`copy` / `mutableCopy` 后保留。即使当前没有适用 Cookie，认证上下文也能禁止回退。本批只提供此标记边界，尚无生产 auth provider 创建上下文。
- Hopper 独立拒绝敏感头，发生在 DNS、临时文件及 runner / argv 构造之前，返回既有 `Unresolved`，不制造匿名成功。只有 headers 的 Hopper API 不能识别请求属性；接收完整请求的包装层负责上下文守卫。
- 匿名请求仍支持 curl。初始请求使用现有媒体净化；重定向使用当前有效上一跳的请求净化，不复用原始 headers。FullPath 跨域剥离后返回原站也不恢复。
- 顺带闭合包装腿相关生命周期：先置取消状态再调用 native cancel，防同步完成重开 curl；重复/迟到 native completion 不重复交付；取消幂等；已完成/取消时不创建进度轮询器。

**实测：最终生产边界测试 446 项全部通过；同一最终测试在开工旧源码上 164 项失败；三项生产源码变异均行为变红；严格串行四套件全部通过；新套件 ASan 通过；10 份最终有效编译日志均 0 error / 0 warning。**

## 3. 行为覆盖

- 三种敏感头各大小写变体及空值：直接 Hopper 的 DNS/runner 次数均为 0；无新增临时 header/body 文件；结果为 Unresolved。
- 受保护原生请求矩阵：头名/空值/native-only 无 Cookie、首发/reissue、同步/延迟完成、纯 403 无 transport error、无 response 的连接错误。原生仍执行一次；交还对象身份不变；已有原生输出字节保持不变。
- 请求接受后，调用者修改 URL、清空或新增认证头：不改变接受时的身份、Range 或回退要求。Foundation 的私有请求类不能靠 `isKindOfClass:NSMutableURLRequest` 判断 copy 的只读语义，最终断言检查独立对象与 URL/头快照行为。
- 标记可复制且不出现在 HTTP 字段；同步 completion 内重新发起 fresh reissue 不丢 native-only 要求。
- 匿名回退实际写入并移动夹具体；捕获 argv 不含人工认证值。取消触发同步 native completion、连续取消、重复/迟到完成均不重开回退或二次交付。
- 四档 Referer × 初始同/跨域，沿真实生产递归走同源 → 跨域 → 返回来源 → 不同端口。断言每跳实际 argv：FullPath 不带 fragment，跨域清除且不回流；Origin/CrossOrigin 仅 origin；None 无头；userinfo/非法来源不传。
- 生产 URLPolicy 的 scheme/userinfo/回环拒绝、mixed public/private DNS 全 IP 拒绝、重定向回环拒绝、无 `-L`/`--location`、Range/截止时间/字节预算参数、超预算拒绝、过期截止时间与预先取消的 Unresolved 语义均保留。
- 人工秘密只在测试内存常量与 fake native 请求中使用；受保护请求 runner 为 0。匿名 argv、真实隔离 RDLog、夹具目录下除测试可执行文件以外的所有文件均扫描，无人工认证标记。

测试构建只将 `NSTemporaryDirectory` 符号重命名到夹具临时目录函数，生产算法未替换；生产构建不使用该宏。macOS 的该 Foundation API 不保证跟随 TMPDIR，不能仅设置环境变量便声称产物隔离。
